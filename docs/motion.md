# 页面动效

沿用现有 React / Framer Motion 11 与 CSS，不添加依赖，不调整页面布局或品牌颜色。

- 页面切换立即更新内容，使用 200ms 淡入与 6px 位移，不等待上一页退场。
- 弹窗与命令面板以 200ms 进入、140ms 退出；退出中的层立即设为 inert，并停止拦截指针。焦点在关闭时返回触发位置，支持退场未结束时重新打开。
- 导航位置标记使用可中断的弹簧过渡；按钮使用轻微按压反馈；开关采用 220ms 缓出。
- 提示仅对位置进行布局动画，避免文本随尺寸变化缩放。评分条使用 scaleX 入场，避免逐帧改变布局宽度。
- 页面整体进入时，不叠加其直属区块的第二轮入场。列表错峰最多等待 120ms，本地模式状态点保持静止。
- MotionConfig 与 useReducedMotion 覆盖 JS 动画；CSS 同时清除动画及过渡延迟。系统选择减少动态效果时，保留简短透明度反馈，取消位移、缩放和布局动画。

## 验证

```sh
node qa/motion-check.mjs
npm run typecheck
npm test
npm run test:usability
npm run build
```

Playwright 浏览器未安装时，可用 `QA_BROWSER` 指定已安装的 Chrome 可执行文件。动效回归在独立浏览器上下文中运行，不读取个人简历数据，覆盖普通/减少动态效果、弹窗退场与快速重开、焦点恢复、命令面板、提示堆叠、连续切页及 375px 手机导航与遮罩关闭。

`.export-qa/motion-results.json` 记录逐帧采样结果；帧间隔数据来自本机 Chrome 的 Vite 开发环境，包含页面加载，不作为其他设备的性能保证。截图只能证明静态布局，动效与低动态模式由逐帧采样及交互断言验证。
